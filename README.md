# 未央 WeYoung Pulse

技术部命题 B：现场互动 MVP。让黑客松参与者从埋头创作走向面对面交流，再把求助、进展与支持同步到现场大屏。

> 本仓库业务源码来自已发布 v8 快照（来源提交 `7d7fcba9c99e34f9d49e8fe9d8ebd6dafc9be673`），不包含后续未发布的 `/join` 补丁。公开网站已部署；2026-10-07 23:14 UTC 云端复核首页与 API 可加载，但用户端访问问题仍在排查，不保证所有网络与浏览器均可访问。请同时参考仓库内源码、演示视频与说明。种子队伍与演示事件不是实际参赛记录。

## 问题、用户与核心流程

现场参与者不容易知道旁边的人在做什么、谁需要帮助，也缺少自然开口的契机。主要用户是参赛者与到场观众；组织者负责大屏展示与内容管理。以上是本项目的问题假设，尚无已完成的用户访谈或效果实测可报告。

1. 从入口进入 `/join`，选择或登记队伍。
2. 翻开、重抽破冰任务；真实完成后主动确认。也可在 `/play` 与伙伴进行 30 秒声浪接力，默认用按钮参与。
3. 发布求助，另一设备认领；发起者或认领者可标记解决。分享一个项目里程碑。
4. 在首页了解作品、进入 `/vote` 选择项目，等待服务器确认正式选票。
5. `/screen` 轮询现场状态，展示最近互动、待回应求助、真实支持票数与加入二维码。

## MVP 范围

| 路径 | 代码中的功能 |
| --- | --- |
| `/` | 四类互动入口；三步说明可手动切换、主动播放或暂停；作品详情与切换 |
| `/join` | 喝彩、抽卡与完成确认；求助发布/认领/解决；进展发布；队伍登记 |
| `/play` | 30 秒、三个交流提示；按钮加火花；可选本机麦克风音量反馈；结束后主动分享破冰事件 |
| `/vote` | 选择作品、正式投票、支持票数横条；独立的本机演示模式 |
| `/screen` | 最近互动、求助状态、票数列表、二维码、主动全屏 |
| `/admin` | 口令控制的隐藏事件、解决求助、清除种子演示事件 |

不包含实名登录、正式评审计分、跨设备身份校验、聊天/站内私信、奖励发放、音频存储、离线提交队列或已验收的大规模并发。当前新版路由的投票页和大屏使用票数横条/列表；旧源码中的曲线模块不等于新版已展示功能。

四个榜单视图已实现切换：人气榜使用服务器聚合的真实票数；声浪是本地娱乐测量；评委榜显示待录入；总榜显示规则待配置。未配置的评委身份、评分维度、权重及合成规则不列为已实现。声浪页本机火花数不上传，不能把它描述为服务器声浪积分；人气支持票也不能解释为综合榜或评委分。

## 量化目标（验收目标，尚非实测结果）

- 新参与者在 60 秒内完成“进入—选择队伍—翻开任务”路径，后续通过计时测试验证。
- 健康网络下，服务器确认的事件在下一次轮询后出现在大屏；代码轮询间隔为 3 秒，拟验收上限为 5 秒，需实测请求耗时。
- 默认按钮模式可完成整轮 30 秒接力；拒绝麦克风权限不阻断游戏。
- 普通顺序请求中，同一浏览器匿名标识最多一张正式票；重试与并发边界单独验证。
- 拟以 50 个同时在线客户端进行读取与提交测试，记录响应分位数、错误率和重复事件；尚未进行该压测。

## API 与数据事实

技术栈：React 19、TypeScript、Vinext、Cloudflare Workers、D1、Drizzle。

| API | 请求与返回 |
| --- | --- |
| `GET /api/state` | 无缓存；返回 `{teams, events, serverNow, voteCounts, totalVotes}`。队伍按创建时间排序，事件流最多最近 150 条；票数通过服务端全量分组计数。事件不返回 `actor`，认领事件的内部关联 `note` 返回空字符串 |
| `POST /api/action` | JSON：`{kind, actor, ...}`；成功返回 `{ok:true}`，部分操作另有 `eventId` 或 `teamId`。业务错误为 400，数据库错误为 500 |
| `POST /api/admin` | JSON：`{pin, action, eventId?}`；`action` 为 `hide`、`resolve`、`clear-demo`；口令错误 403、事件不存在 404；生产未配置口令拒绝操作 |

`kind` 支持 `team`、`cheer`、`icebreak`、`help`、`milestone`、`vote`、`claim`、`resolve`。除登记队伍外，操作需要有效 `teamId`。认领/解决需要 `targetId`；抽卡需要 `label`；求助 `note` 至少 6 个字符。后端会检查队伍存在、操作频率和权限。正文会存入数据库并公开展示，勿填联系方式等敏感内容。

例：在独立测试库操作，不要把此样例投到正式活动库。

```http
POST /api/action
Content-Type: application/json

{"kind":"icebreak","actor":"demo-device-0001","teamId":"neon","label":"与伙伴互相介绍项目"}
```

初次读取无队伍的数据库时，自动创建 `neon`、`404`、`wave`、`loop` 四支示例队伍及三条 `demo=1` 示例事件。页面通过队伍 ID 标注示例名单。真实提交的事件为 `demo=0`；“真实”指服务器接受的事件，并不证明队伍或参与者经过身份核实。

投票页本机演示只改 React 本地状态，不调用正式投票提交，不写数据库；刷新后演示票数消失。它可以使用示例队伍作为展示对象。正式票数只统计 `kind=vote`、`status=open`、`demo=0` 的事件，隐藏票不计入。清除演示事件不删除示例队伍，也不清除本机演示状态。

限票规则是同一 `actor` 在当前数据库中总共一票，不是每项目一票；没有活动 ID、日期或时间窗口区分。隐藏既有票不恢复投票额度。当前数据库如果复用于下一场活动，需要另行设计活动隔离与额度重置，不能声称已支持多活动。

## 弱网、并发与冷启动

- 读取失败显示连接提示，并继续每 3 秒重试；旧快照可能仍保留，不能当成最新状态。写入失败会提示用户，无离线排队或自动补交；服务器确认前不算完成。
- 首次运行需先创建数据库表，之后种子逻辑填充展示内容；不能把种子数据解释为已有用户或真实投票。未测冷启动延迟。
- 每个匿名 `actor` 在一分钟内累计达到 10 条事件时拒绝后续提交；喝彩对同队间隔 5 分钟，重复任务/同队同里程碑在一天内限制。该频率检查不是强并发限流，且队伍登记不产生事件，不能据此承诺所有请求严格每分钟 10 次。
- 求助认领使用 `open` 状态条件更新；只有一次状态更新成功者可进入认领流程。解决由发起者或认领者校验，管理员另有权限。
- 正式投票以单条 `INSERT ... SELECT ... WHERE NOT EXISTS` 原子写入。本地 D1 同设备 8 个并发请求接受 1 个、拒绝 7 个，数据库仅 1 条票。网络丢失响应时应先重新读取状态。
- 全量 `voteCounts/totalVotes` 聚合独立于最近 150 条动态。本地新增 161 票时，动态仍为 150 条，聚合准确增加 161 票。帮助列表仍受最近动态窗口限制。
- 人气榜使用真实聚合票数，正票前三展示领奖台，同票并列；名次重排动画尊重减动效。声浪仅本地娱乐测量入口，未经分贝校准。评委榜待录入，总榜规则待配置，不生成未经确认的官方总分。

## 浏览器权限与隐私

匿名标识通过 `crypto.randomUUID()` 生成并保存在 `localStorage` 的 `pulse-actor`。求助所有权与认领记录也存于本机，用于界面按钮；服务器另行验证权限。清空存储、换浏览器或设备会改变身份，也可能导致无法继续处理原有求助；不是防作弊的实名机制。

麦克风可选，通过 `getUserMedia` 与 Web Audio 仅分析当前音量；代码不录音、不上传原始音频、不做语音识别，也不提交火花数。授权失败仍可用按钮。关闭、结束、切到后台或离开页面时有停止音轨/关闭音频上下文的逻辑，尚需实机确认浏览器的权限指示灯变化。麦克风需浏览器允许的安全上下文；手机通过普通局域网 HTTP 访问可能无法授权。

全屏只由用户点击触发；二维码由当前页面 `origin + /join` 生成。电脑上的 `127.0.0.1` 二维码不能让另一台手机连接到这台电脑。对外使用需真实可访问地址与相应访问权限。

## 本地运行与生产部署准备

要求 Node.js 22.13+ 和 npm。在完整独立源码副本根目录执行，首次初始化数据库表的 SQL 只运行一次：

```powershell
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_massive_hellfire_club.sql
npm run dev
```

Windows 可移植路径的开发脚本默认参数为端口 5173；以本次进程输出的地址为准。也可在构建后用 `npm start` 进行本地 Worker 预览。构建读取 `.openai/hosting.json`，`db/index.ts` 要求 D1 绑定名为 `DB`。当前工程保留 v8 的 Sites 配置元数据；它不是登录凭据，也不能用作你自己的部署身份。独立部署须替换为你自己的项目配置并验证干净克隆，不能复制原项目标识作为独立部署方案。

生产需要新部署目标、D1 数据库绑定 `DB`、迁移与独立 `ADMIN_PIN`。开发默认口令为 `pulse-demo`；生产没有默认口令。以下仅示意独立 Cloudflare 部署命令，配置占位符不能直接执行；先由部署负责人提供已核对的独立 Worker 配置与数据库名，确认迁移不会碰原活动数据。下列独立 Worker 部署示例尚未执行验证。

```powershell
npm run build
# <独立数据库名> 与 <独立Worker配置路径> 必须先替换并核对
npx wrangler d1 execute <独立数据库名> --remote --config <独立Worker配置路径> --file drizzle/0000_massive_hellfire_club.sql
npx wrangler secret put ADMIN_PIN --config <独立Worker配置路径>
npx wrangler deploy --config <独立Worker配置路径>
```

托管 Sites 使用原生发布流程与数据库绑定，不能把上述独立 Worker 示例当作 Sites 发布命令。现有公开网站为 https://pulse-exchange-hackathon.lucyke915.chatgpt.site 。v8 已于 2026-10-07 16:01 UTC 发布成功，来源提交 `7d7fcba9c99e34f9d49e8fe9d8ebd6dafc9be673`。该版本将五个正在使用的界面文件中的 18 处客户端导航链接改为原生链接，以修复点击后无法跳转的问题；未改变 API、数据库逻辑、样式、素材或访问范围。
