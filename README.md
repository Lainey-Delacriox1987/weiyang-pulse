## 功能与使用流程

1. 首页查看作品与现场动态，抽取破冰任务预览。
2. 在 `/join` 选择或登记队伍，完成破冰、发布求助、认领和解决求助、分享里程碑。
3. `/play` 提供 30 秒声浪接力，默认使用按钮；麦克风为可选功能。
4. `/vote` 支持选择作品并提交正式选票，也提供独立的本机演示模式。
5. `/screen` 展示现场互动、求助与支持票数，并提供加入二维码。
6. `/admin` 通过独立管理口令处理内容；生产环境未配置口令时拒绝管理操作。

人气榜使用服务器聚合票数。声浪用于本地娱乐测量；评委榜和总榜需要进一步配置，不生成未经确认的官方评分。示例队伍与演示事件不代表真实参赛记录。

## 技术与运行

React 19、TypeScript、Vinext、Cloudflare Workers、D1、Drizzle。要求 Node.js 22.13+ 和 npm。

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_massive_hellfire_club.sql
npm run dev
```

数据库迁移用于新的本地数据库，勿不经核对地对生产库重复执行。以开发进程输出的端口为准；构建后也可用 `npm start` 进行本地 Worker 预览。

`.openai/hosting.json` 保留原项目配置元数据，不是认证凭据。独立部署需使用自己的项目配置、D1 数据库绑定 `DB` 和生产 `ADMIN_PIN`。`.env.example` 只有开发示例；不要把真实密码、访问令牌或私有 `.env` 提交到仓库。

## 数据、隐私与边界

- 匿名身份保存在当前浏览器的本地存储中，不是实名登录。换设备或清空存储会改变身份。
- 正式投票由服务器校验同一匿名标识的投票额度；本机演示票不写入正式数据库。
- 求助与里程碑正文会存储并公开展示，请勿填写联系方式等敏感个人资料。
- 麦克风仅分析本机音量，不录音、不上传原始音频、不做语音识别。不授权仍可使用按钮模式。
- 无离线提交队列；写入以服务器成功响应为准。
- 没有已验证的实名防作弊、跨设备身份一致性、大规模并发或官方综合评分能力。

新版已通过项目构建检查；真实手机、完整跨浏览器回归、麦克风实机权限表现、弱网恢复和压力测试仍需独立验证。不能将旧版本局部验收或一次构建成功视为全部功能通过。
